OPTION 4. Search & Analyse a Stock (signal + candlestick chart)
=====================================================================================
KYA KARTA HAI:
  Step 1 (Search): ek keyword (jaise "tata" ya "BANK" ya "Pharma") daalo, matching
  stocks unke last price ke saath dikhenge.
  Step 2 (Analyse): Stock ID daalo (Enter = skip) -> ek report:
    - Last close aur date
    - Returns: 1 din, 1 mahina, 3 mahine, 1 saal
    - 52-week high / low
    - Risk: volatility (% per saal) aur max drawdown
    - 20-day aur 50-day moving average
    - RSI (14): 70 se upar = overbought, 30 se neeche = oversold
    - SIGNAL: BULLISH / BEARISH / NEUTRAL
  Plus chart: charts/stock_analysis_<SYMBOL>.png (candlestick + moving averages +
  volume + RSI) jo window me bhi khulta hai.

KAISE KAAM KARTA HAI:
  1. SQL ka LIKE '%keyword%' symbol, company aur sector naam teeno me dhundta hai.
     Keyword "?" placeholder se pass hota hai (SQL injection se safe).
  2. analyse_stock(id):
       dma_20 / dma_50 = close.rolling(20 / 50).mean()
       RSI = 100 - 100 / (1 + avg gain(14 din) / avg loss(14 din))
       volatility = daily_return.std() x sqrt(252)
       max drawdown = (close / pichla sabse uncha close - 1) ka minimum
       Signal: price > 50-DMA aur 20-DMA > 50-DMA -> BULLISH
               price < 50-DMA aur 20-DMA < 50-DMA -> BEARISH, warna NEUTRAL
  3. plot_stock_analysis(id): pichle 120 din. Candle = vlines (high-low) + bar
     (open-close body), green agar close >= open warna red.

OPTION 7. Buy a Stock (Auto 8% stop-loss)
=====================================================================================
KYA KARTA HAI:
  Investor ke liye shares kharidta hai. Buy price = aaj ka market price. Stop-loss
  apne-aap buy price se 8% neeche set hota hai.

KAISE KAAM KARTA HAI:
  1. Investor ID, Stock ID, Quantity lo. Quantity 1 se kam -> error.
  2. Check: investor exist karta hai? stock exist karta hai? Nahi -> error, kuch
     save nahi.
  3. buy_price = _latest_price(stock)
     stop_loss = buy_price x (1 - 0.08)      (STOP_LOSS_PCT = 0.08, db_setup.py)
  4. INSERT INTO trades (buy_date = aaj, sell_date = NULL, sell_price = NULL)
     -> sell_date NULL ka matlab "position abhi open hai".
  5. commit -> "Trade #ID ... bought ... Investment ... stop-loss" print.

=====================================================================================
OPTION 8. Sell a Stock (Auto profit / loss calculation)
=====================================================================================
KYA KARTA HAI:
  Open position bechta hai aur profit ya loss calculate karta hai.

KAISE KAAM KARTA HAI:
  1. Trade ID lo (Option 9 ya 10 se dekh sakte ho).
  2. Trade + stock + investor JOIN karke details laao.
  3. sell_date pehle se bhari hai -> "already sold" message.
  4. sell_price = aaj ka price
     pnl        = (sell_price - buy_price) x quantity
     return %   = sell_price / buy_price - 1
     held days  = aaj - buy_date
  5. UPDATE trades SET sell_date = aaj, sell_price = ...
  6. pnl > 0 -> "PROFIT BOOKED", pnl = 0 -> "BREAK-EVEN", warna "LOSS BOOKED".

OPTION 11. Data Cleaning & Aggregation Report          [SYLLABUS: Unit 2]
=====================================================================================
KYA KARTA HAI:
  Terminal me ek report print karta hai jo dikhata hai ki raw data ko kaise saaf aur
  summarize kiya gaya. Isme 5 parts hain:
    [1] Raw tables ka size (rows x columns)
    [2] Missing values: price_history.close ke NULL (data feed gap) aur trades ke
        sell_date / sell_price NULL (= open positions), duplicate rows
    [3] Cleaning steps (forward fill, daily return, holding days, P&L, status)
    [4] Aggregation: sector x status pivot table
    [5] Summary statistics (mean, std, min, max...) of holding_days, return_pct,
        pnl aur daily_return

KAISE KAAM KARTA HAI:
  load_raw_data() + price_history -> isnull().sum() se missing values ->
  get_clean_prices() aur get_cleaned_trades() se clean tables -> pivot_table() aur
  describe().

  Cleaning rules:
    close (missing) = usi stock ka pichle din ka close  (groupby + ffill)
    daily_return    = close / pichla close - 1   (x 100)
    holding_days    = sell date (ya aaj) - buy date, minimum 1
    pnl             = (exit price - buy price) x quantity
    status          = Profit Booked / Loss Booked / Open - In Profit / Open - In Loss

  Syllabus ki self-study case study "Supply Chain & Logistics Dashboard" maangti
  hai (shipment logs, route mapping, delivery KPIs, filtering by region). Isko stock
  market se joda gaya hai: watchlist ki manufacturing companies (Pharma, Auto,
  FMCG) apni factory se maal JNPT port (Navi Mumbai) bhejti hain. Sawaal: "Jo
  company time pe deliver karti hai, kya uska share bhi achha chalta hai?"

KYA KARTA HAI:
    1. Region chuno: 0 All, 1 North, 2 West, 3 South, 4 East  (= filtering by region)
    2. Terminal me: shipments, containers, freight cost, on-time delivery gauge
       (target 90%), average transit days.
    3. DELIVERY STATUS KPIs: Delivered On-Time / Delivered Late / In Transit /
       Delayed In Transit (count aur %).
    4. ROUTES table: har factory city -> km, shipments, avg days, late count
       (= route mapping, table form me).
    5. COMPANY SCORECARD: har company ka on-time %, avg delay aur 1-year share
       return + correlation r (positive = time pe deliver karne wale ka share zyada
       badha).
    6. Dashboard image banta hai: charts/supply_chain_dashboard_<region>.png
       (KPI cards, gauge, route map arrows, status by region, monthly on-time trend,
        carrier delay, on-time % vs share return scatter) aur window me khulta hai.

KAISE KAAM KARTA HAI:
  1. get_cleaned_shipments(region): shipments + stocks + sectors JOIN,
       transit_days = delivery (ya aaj) - dispatch
       delay_days   = delivery (ya aaj) - expected, minimum 0
       status       = upar ke 4 me se ek
     phir region filter.
  2. groupby('origin_city') se routes table.
  3. get_company_logistics_scorecard(): company-wise on-time % + get_stock_summary()
     ka return_1y.
  4. plot_supply_chain_dashboard(region) gridspec se 3-row dashboard banata hai.

  Shipment data kahan se aaya:
    db_setup.seed_shipments() 180 shipments banata hai. Distance haversine_km() se
    (latitude/longitude se asli doori). Expected days = distance/450 + 1.
